# Personal Health Advisor Agent

## Project Overview

The Personal Health Advisor is an AI agent designed to provide personalized fitness and nutrition guidance based on a user's goals, preferences, location, and current weather.

The original IBM lab uses watsonx.ai Agent Lab with the Llama 3.3 70B Instruct model, together with Google Search and Weather tools.

This implementation reproduces the same core agent workflow using free/open tools.

## Main Features

* Personalized workout recommendations
* Meal and nutrition suggestions
* Weather-aware workout recommendations
* Location-based weather information
* Web information retrieval
* Conversational interaction
* LLM-powered responses
* Simple Gradio interface
* No IBM Cloud account required

## How the Agent Works

1. The user submits a health, fitness, or nutrition question.
2. The agent examines the request.
3. If weather information is relevant, it calls the Weather Tool.
4. If additional information is required, it calls the Web Tool.
5. Retrieved information is provided to the LLM.
6. The LLM generates a personalized response.
7. The response is displayed to the user.

## Why a Smaller Model Is Used

The original IBM lab uses Llama 3.3 70B Instruct through IBM's infrastructure.

A 70B model is too large for practical free local/Colab execution in this project, so Qwen 2.5 1.5B Instruct is used instead.

The purpose of the project is to reproduce the **agent architecture and workflow**, rather than reproduce IBM's exact hosted model.
